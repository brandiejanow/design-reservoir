About

A living reference, not a static list.

Design Reservoir began as a manually maintained collection of resources for designers. It now lives as a versioned public directory so links can be checked, moved resources can be updated, and the collection can grow across disciplines and geographies.

The underlying dataset is maintained on GitHub, while this page is the human-facing interface.
